# Nado Bot — экономный фарм поинтов на Nado

Бот котирует post-only лимитки по обе стороны от mid на 1–2 ликвидных перпах.
Он не платит taker-комиссию, держит маленький инвентарь, снимает ордера при
резких движениях и останавливается при дневном убытке выше лимита. Ещё он
считает **цену одного поинта**: сколько $ ты потратил на один поинт.

> ⚠️ Это не «бесплатные поинты». Ты платишь maker-комиссией (если она не нулевая),
> adverse selection (лимитки исполняются, когда цена идёт против тебя) и фандингом.
> Сначала testnet, потом mainnet с маленьким депозитом.

## Как устроена безопасность

- Твой ключ MetaMask бот **не видит и не хранит**.
- `keygen` создаёт отдельный бот-кошелёк. Ты один раз подписываешь в MetaMask
  сообщение **LinkSigner**. После этого бот-кошелёк может подписывать ордера
  от имени твоего субаккаунта Nado.
- Подпись происходит на локальной странице `http://127.0.0.1:8765`, которую поднимает
  сам бот. Она доступна только на твоём компьютере.
- Отвязка: `python -m nadobot unlink` или через интерфейс Nado.
- ⚠️ По документации Nado linked signer может выполнять «любые executes» на субаккаунте.
  Возможно, это включает вывод средств. Пока не проверишь, считай, что кто
  украдёт файл `.env`, тот сможет распоряжаться депозитом. Поэтому держи на
  Nado только рабочую сумму, файл `.env` никому не показывай, а при подозрении
  на утечку сразу делай `unlink`.
- Лимит Nado: не больше 50 привязок/отвязок за 7 дней. Для привязки на
  субаккаунте должно быть минимум 5 USDT0.

## Установка (Windows)

1. Поставь **Python 3.12** (или 3.13; **3.14 не подходит**: на нём SDK Nado под Windows не ставится):
   https://www.python.org/downloads/release/python-3128/ → «Windows installer (64-bit)».
   При установке отметь **Add python.exe to PATH**.
2. Скачай бота: на GitHub открой ветку `claude/tender-bell-t692ux` → **Code → Download ZIP**,
   распакуй и перенеси папку `nado-bot` куда удобно, например в `C:\nado-bot`.
   Путь лучше без кириллицы и пробелов.
3. Дважды кликни **`install.bat`**. Он создаст окружение, поставит зависимости, создаст бот-кошелёк
   и откроет `.env` в Блокноте. Впиши туда `NADO_OWNER=0x…` (адрес MetaMask) и сохрани.
4. В папке бота кликни по адресной строке Проводника, введи `cmd` и нажми Enter. Откроется консоль, дальше:
   ```
   nado status
   nado link
   ```
5. Запуск: двойной клик по **`run.bat`**. Остановка: **Ctrl+C** в окне. Не закрывай окно крестиком,
   иначе ордера не снимутся (хотя через 2 минуты истекут сами).
6. Аварийно всё закрыть: **`panic.bat`**.

Все команды из таблицы ниже на Windows пишутся как `nado <команда>`, например `nado report`.

**Защита `.env` на Windows.** Там лежит ключ бот-кошелька. Не храни папку в OneDrive/Dropbox
и не давай доступ к ПК посторонним. Антивирус может ругаться на `.bat`: это нормально,
скрипты открытые, их можно прочитать в Блокноте.

**Чтобы бот не засыпал:** Параметры → Система → Питание → «Переводить в спящий режим» → *Никогда*
(пока бот работает). Для 24/7 лучше VPS.

## Установка (macOS / Linux)

```bash
git clone -b claude/tender-bell-t692ux https://github.com/xstthx777/Flowise.git nado-src
cp -r nado-src/nado-bot ~/nado-bot && cd ~/nado-bot
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env              # впиши NADO_OWNER = адрес MetaMask
cp config.example.yaml config.yaml
python -m nadobot keygen
```

## Первый запуск — на testnet

1. Открой testnet Nado в браузере с MetaMask, получи тестовые средства и внеси
   депозит (минимум 5 USDT0).
2. `nado status` (macOS: `python -m nadobot status`) проверит, что субаккаунт виден.
3. `python -m nadobot link` откроет страницу, там нажми «Подписать в MetaMask».
   В окне подписи проверь, что `signer` начинается с адреса бот-кошелька.
4. `python -m nadobot status` должен показать: Linked signer … (бот привязан).
5. В `config.yaml` оставь `dry_run: true`, запусти `python -m nadobot run`
   и посмотри в логе, какие котировки бот считает.
6. Поставь `dry_run: false` и запусти снова. Пусть поработает на testnet хотя бы сутки.
7. Только потом: `mode: mainnet`, заново `link` (это другая сеть) и маленький депозит.

## Команды

| Команда | Что делает |
|---|---|
| `python -m nadobot status` | equity, позиции, привязка, комиссии |
| `python -m nadobot run` | запуск (Ctrl+C снимает ордера) |
| `python -m nadobot panic` | снять ордера и закрыть позиции |
| `python -m nadobot points 1234` | записать текущее общее число поинтов (из интерфейса Nado) |
| `python -m nadobot flow 100` / `flow -50` | отметить депозит/вывод, чтобы отчёт был честным |
| `python -m nadobot report` | затраты, $/день, цена поинта |

Логи пишутся в `data/bot.log`, история — в `data/ledger.sqlite`.

## Настройка экономии (`config.yaml`)

- `offset_bps`: насколько далеко от mid стоят ордера. Шире — меньше сделок, но и
  меньше потерь на adverse selection. Уже — больше объёма и больше потерь.
- `order_size_usd`: объём за одно исполнение.
- `max_position_usd` / `hard_position_usd`: мягкий и жёсткий лимиты инвентаря.
- `max_daily_loss_usd`: kill-switch.

Как подбирать: раз в неделю вписывай `points`, смотри `report` и сравнивай
**цену поинта** с другими вариантами (волт NLP, ручная торговля). Масштабируй
только то, что дешевле.

## Запуск 24/7

Mac засыпает, поэтому для круглосуточной работы удобнее VPS (Linux, 5$/мес):
```bash
nohup python -m nadobot run > /dev/null 2>&1 &
```
или systemd-сервис. Перед запуском на VPS сделай `unlink`/`link` с новым ключом.
